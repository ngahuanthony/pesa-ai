## Frontend build output

**Rule:** Do not track `artifacts/pesa-ai/dist`. Railway must use only the Vite output generated by its build command.

**Why:** Tracked build files can overlay the fresh Nixpacks build in Railway's final image. This caused a stale tracked index to reference a missing hashed bundle even though the new backend and assets had deployed.

**How to apply:** Keep `dist` ignored, run the production build only for validation, and never force-add its output. After deployment, verify the root HTML asset path returns JavaScript rather than the SPA fallback.
